# Guide utilisateur (par rôle)

L'application s'ouvre avec un lien envoyé par Anthony. Sur iPhone, ajoutez-la à l'écran d'accueil (Safari → Partager → « Sur l'écran d'accueil »).

Deux mentions reviennent partout :

- **donnée indisponible** : l'information manque. Ce n'est pas zéro. Survolez ou touchez le texte pour savoir ce qui manque.
- **incomplet** : le chiffre est calculé sans certaines lignes dont une donnée manque.

Rien n'est jamais supprimé : « Archiver » retire une ligne des calculs mais la conserve dans Google Sheets.

---

## Anthony – Administrateur

**Après chaque activité (moins d'une minute)**
1. Séances → **Séance rapide**.
2. Choisissez l'activité : horaire, terrains, coach et capacité de la dernière séance du même type se remplissent.
3. Indiquez inscrits, présents, absents, no-shows (ou laissez vide et utilisez **Présences** pour la liste nominative).
4. **Enregistrer**.

**Chaque semaine**
- Heures coachs → **À valider** : cochez, **Valider la sélection** ; ou **Renvoyer en correction** avec un motif.
- Heures coachs → **À payer** : après la facture, cochez et **Marquer payé** (référence obligatoire).
- Qualité des données : traitez d'abord les lignes **bloquantes**.
- Rapports → **A. Résumé hebdomadaire** ; rédigez les priorités de la semaine suivante.

**Chaque mois : chiffres Power BI**
1. Au club, ouvrir Power BI et noter les chiffres du mois écoulé (membres du club, membres qui ont joué au padel, membres qui ont réservé, réservations, nouveaux membres, âge moyen…).
2. Communauté & pénétration → **Saisir les chiffres Power BI d'un mois** → choisir le mois → remplir ce qui est disponible → Enregistrer. Une case vide reste « inconnue ».
3. Le taux de pénétration, la part des membres qui réservent et les évolutions apparaissent dans le tableau de bord et dans le bilan pour Laurent.

**Programme gratuit** : Communauté & pénétration montre, pour les Tasters, Afterworks et New to Padel, les séances réalisées par rapport à l'objectif hebdomadaire, le remplissage, les participants, les nouveaux joueurs recrutés et la conversion des Tasters. Les inscriptions venant de l'application des membres s'importent via Imports → « Liste de présences ».

**Chaque mois / trimestre**
- Rapports → **B. Rapport financier mensuel**, **C. Bilan pour Laurent**, **D. Rapport trimestriel** → Imprimer / PDF ou CSV.

**Académies**
- Académies → Offres : une formule = un tarif confirmé + un nombre de séances. Pour changer un tarif, archivez l'offre et créez-en une nouvelle avec sa date d'effet.
- Académies → Cycles → **Générer les séances** (les vacances encodées dans Paramètres sont sautées).

**Paramètres** : date d'ouverture indoor, horaires des terrains, taux des coachs (toujours **ajouter** une nouvelle ligne datée, ne jamais écraser), heures de pointe, vacances, budget, types d'activité, utilisateurs, droits par rôle.

**Imports** : 1) type d'import et fichier CSV/Excel ; 2) vérifier l'association des colonnes ; 3) lire le contrôle (doublons, lignes incomplètes) ; 4) importer. Un import se retire d'un clic (« Annuler l'import »).

## Gilles et les autres coachs

**Encoder une intervention (depuis le téléphone)**
1. Heures → **Nouvelle intervention** (la date du jour est préremplie).
2. Choisissez la **séance du jour** si elle existe : horaire et type se remplissent. Sinon saisissez début, fin et type ; la durée se calcule.
3. Remplacement : activez « Remplacement » et indiquez le coach remplacé. Séance annulée : activez « Séance annulée » et ajoutez un commentaire.
4. **Soumettre à Anthony** (ou « Enregistrer en brouillon » pour finir plus tard).

**Après validation** les heures ne sont plus modifiables. Si une erreur est découverte : ouvrez la ligne dans « Mon historique » → **Demander une correction**.

**Présences** : Séances → bouton **Présences** → Présent / Absent (prévenu) / No-show / Désinscrit pour chaque membre, **Tous présents** pour aller vite, « Ajouter un membre » par son identifiant.

## Réception

- Paiements → **À encaisser** : membres inscrits avec un solde. **Encaisser** préremplit le montant dû ; choisissez le mode et la référence.
- Paiements → **À vérifier** : contrôlez la référence, puis **Vérifié**.
- Académies → Inscriptions → **Nouvelle inscription**. Entrée en cours de cycle : indiquez la première séance due et le nombre de séances restantes (seules celles-ci sont facturées).
- Satisfaction → **Nouvel avis membre** pour saisir un questionnaire papier (identifiant membre facultatif).
- Les paramètres financiers (tarifs, taux, P&L) ne sont pas accessibles, sauf autorisation d'Anthony.

## Laurent et les managers (lecture seule)

- **Tableau de bord** : choisissez Semaine / Mois / Trimestre / Depuis l'ouverture / Personnalisée ; chaque carte compare à la période précédente. Le badge « Période en cours » signale des chiffres provisoires.
- **Filtres** : terrain, indoor/outdoor, activité, niveau, coach, adulte/junior, gratuit/payant.
- **P&L padel** : encaissé, reconnu, restant à délivrer, coûts, marge ; « Détail » montre les lignes sources.
- **Rapports** → C. Bilan pour Laurent → **Imprimer / PDF** (sur iPhone : Partager → Imprimer → pincer l'aperçu → Partager en PDF).
- Le NPS est toujours accompagné du nombre de réponses **n** ; en dessous de 30 réponses, il est indicatif.
